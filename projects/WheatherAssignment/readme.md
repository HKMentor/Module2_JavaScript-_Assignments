# 🌦 Season Selector / Weather Card

**Project Link:** [https://wheathercard-byhk.netlify.app/](https://wheathercard-byhk.netlify.app/)  

## Description
Season Selector ek interactive web application hai jo user se season select karne ke liye prompt karta hai aur phir ek stylish card ke saath us season ka **weather/seasonal theme** display karta hai. Har season ke liye **dynamic background**, **image**, aur **description** show hota hai.

Ye project **HTML, CSS, aur JavaScript** ka use karke banaya gaya hai, aur fully responsive hai mobile aur desktop ke liye.

---

## Features
- 🌈 **Dynamic Backgrounds** – Season select karte hi page ka background change hota hai.  
- 🎨 **Season Cards** – Har season ke liye alag card design with image aur description.  
- 🔁 **Choose Again Button** – User manually dobara season select kar sakta hai.  
- 📱 **Responsive Design** – Mobile, tablet, aur desktop ke liye compatible.  
- ⚡ **Smooth Animations** – Card aur image hover animations ke sath.  

---

## JS Functionality / Implementation
- `showSeason()` – Prompt ke through season input leta hai aur card generate karta hai.  
- Dynamic backgrounds – CSS `linear-gradient` ko JS se dynamically apply kiya.  
- Prompt & Validation – Agar user invalid season type kare to error card show hota hai.  
- Buttons (`Choose Again`) – User ko allow karta hai dobara input dene ke liye.
