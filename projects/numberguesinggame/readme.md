# 🎲 Number Guessing Game

A fun Number Guessing Game built with **HTML, CSS, and JavaScript**.  
User has **3 chances** to guess a random number between **1–10**.

## 🚀 Features
- Random number generation
- 3 attempts with feedback (Too high / Too low)
- Reset button to restart game
- Light/Dark mode toggle 🌙☀️
- Responsive and clean UI

## 🛠️ Tech Used
- **HTML** → Structure  
- **CSS** → Styling & Themes  
- **JavaScript** → Game logic & DOM handling  

## 🎮 How to Play
1. Enter a number between 1–10  
2. Press **Guess**  
3. See result (Win / Lose / Hint)  
4. Reset & play again
